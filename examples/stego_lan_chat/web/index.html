No profile guarantees resistance to steganalysis. Deterministic mode is instant and printable, but its public grammar and length are fingerprintable; word replacement or paraphrasing destroys it. Arithmetic mode is slow and exact-text only. Fast Unicode mode is compact but uses detectable default-ignorable selectors. Fast hybrid mode also has a handcrafted detectable distribution. Compact HYDRA leaks encrypted length, and WebRTC encrypts the carrier in this integration demo.
